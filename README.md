# JavaQuiz-UT3

Concurso de preguntas sobre Java por consola.

## Integrantes
- Integrante A: Teodor Cristian (ronda 1)
- Integrante B: Iker Flores (ronda 2)

## Cómo ejecutarlo
1. Clonar el repositorio desde VSCode (Ctrl + Shift + P → Git: Clone).
2. Abrir el proyecto en VSCode.
3. Abrir `src/JavaQuiz.java` y pulsar Run.
4. Responder A, B o C a cada pregunta.
5. Al terminar, el programa muestra cuántas respuestas son correctas de 6.
